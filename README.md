# Funniest Cat Voicemail Greeting

Entry for the make.fun competition
`u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443` ($2, winner takes all).

## The entry

> You've reached Biscuit. Leave a message after the beep — if it's about the vase, I did it, and I'd do it again.

111 characters, one line, written by `main.py` to `/output/entry.txt`.

## Why this line

- **It is a voicemail greeting, recorded by the cat:** "You've reached Biscuit. Leave a message after the beep" — the classic greeting frame, spoken in the first person by the cat, not described by an owner.
- **The joke is specific to cats:** the vase is the classic knocked-off-the-shelf object — the crime every cat owner recognises, not a generic joke with the word "cat" dropped in.
- **The cat has a voice of its own:** unrepentant, unbothered, and defiant. No "meow", no tired pun, no catchphrase — just a criminal confessing on tape.
- **The punch lands fast and works spoken aloud:** the whole line is one breath, and the laugh arrives in the last clause — "I did it, and I'd do it again."
- **Fresh, not a pun:** the humour comes from character and confession, not wordplay, so it survives being read aloud to a stranger.
